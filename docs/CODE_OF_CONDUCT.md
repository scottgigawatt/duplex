# Duplex Code of Conduct 🎭📺

Duplex welcomes contributors, users, bug reporters, documentation editors, and
the brave souls who can explain Docker networking without drawing a pentagram.
Everyone participating in this project is expected to help keep the production
safe, respectful, and useful.

## Expected behavior 🌟

- Be respectful, patient, and constructive.
- Critique code and ideas, not people.
- Assume good intent while still asking for clear evidence.
- Welcome different backgrounds, identities, experience levels, and viewpoints.
- Share enough context for others to reproduce a problem safely.
- Protect private data and report vulnerabilities through secure channels.
- Accept correction and repair harm when a mistake happens.

## Unacceptable behavior 🚫

- Harassment, threats, discrimination, or demeaning language.
- Sexualized attention or imagery directed at another participant.
- Trolling, sustained disruption, or deliberately inflammatory behavior.
- Publishing private information or credentials without explicit permission.
- Pressuring anyone to reveal infrastructure, account, or identity details.
- Retaliation against someone who reports a conduct or security concern.

The public documentation may be funny. Conduct enforcement is not a comedy bit.

## Scope 🎬

This policy applies in repository issues, pull requests, reviews, discussions,
Discord spaces associated with the project, and private communication related
to project work. It also applies when someone publicly represents Duplex or its
community.

## Reporting a problem 🛡️

Report conduct concerns privately to the repository owner. If GitHub private
reporting is appropriate, use the repository's **Security** tab. Otherwise ask
for a private maintainer channel through
[🔥HADES🔥](https://discord.gg/BpEGzWwGYf) without posting sensitive details in
public.

Include what happened, where it happened, relevant links or screenshots, and
any immediate safety concern. Reports will be handled as confidentially as
practical.

## Enforcement 📋

The maintainer may edit or remove content, issue a warning, limit participation,
temporarily suspend access, or permanently ban someone depending on severity,
pattern, and risk. Credible threats, doxxing, credential exposure, or targeted
harassment may result in immediate removal without a warning scene.

Enforcement decisions should focus on safety, accountability, and preventing
repeat harm. Good-faith disagreement about technical decisions is not a conduct
violation.

Thank you for helping the project keep the jokes in the README and the drama on
the screen. 🍿
