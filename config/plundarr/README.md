# The Plundarr Crossover Event 🏴‍☠️📺

Duplex keeps Plex's supporting cast on schedule. **Plundarr** kicks open the
studio door, commandeers the craft-services table, and deploys the larger media
automation armada.

> [!NOTE]
> Plundarr is a separate project with its own Compose stack, configuration,
> security model, and migration guide. Duplex does not require it.

If ye want indexers, download clients, VPN routing, request management, library
automation, dashboards, backups, and enough YAML to qualify as nautical
literature, chart a course to
[scottgigawatt/plundarr](https://github.com/scottgigawatt/plundarr).

Read Plundarr's current README and setup documentation instead of copying old
service lists from this cameo. The fleet changes; the sea has release notes.

> [!WARNING]
> The crossover has a bigger cast and a wider blast radius. Back up first,
> protect credentials, and validate its generated chart before sailing.
